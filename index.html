Status auf allen Geräten

Der Status («kontaktiert», «abgesagt» …) wird in diesem Browser gespeichert. Damit er auf allen Geräten gleich ist, trage einen GitHub-Schlüssel ein. Er wird nur in diesem Browser gespeichert und nur benutzt, um die Datei data/status.json in deinem Repo zu speichern.

So erstellst du den Schlüssel (2 Minuten)
  1. Auf GitHub: Profilbild → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name z. B. «Hobbyraum-Radar», Ablauf nach Wunsch.
  3. Repository access: «Only select repositories» → Hobbyraum.
  4. Permissions → Repository permissions → Contents: «Read and write». Sonst nichts.
  5. Token kopieren und hier einfügen.

Angaben für die E-Mail-Entwürfe

Optional. Was du hier einträgst, wird in jeden Entwurf eingesetzt. Die Angaben bleiben in diesem Browser und werden nie ins Repo geschrieben. Ohne Angaben enthalten die Entwürfe Platzhalter in eckigen Klammern.
